## 0. 参考:项目方给的 HUD 示意图

项目方另给了一张示意图(「随便生成的」,是方向不是像素级规格)。从中提取出的**结构词汇**:

| 元素 | 图里的样子 |
|---|---|
| 面板框 | 四角**切角/角标**的双层框线,不是圆角卡片。外框细、内框更细,四角有 L 形角标 |
| 电路走线 | 页头、表头分隔线、单元格里都有 PCB 式细线走线与节点圆点 |
| 侧栏项 | 一块块**带斜切角的板**,图标 + 中文大字 + 下方英文小号大写字母(宽字距) |
| 选中态 | 板整体**辉光描边** + 内发光,不是背景填充 |
| 表格 | 列头大写宽字距,列头之间有走线相连;每行右端一条**状态指示色条** |
| 统计块 | 左侧一条色条 + 上方极小号大写标签 + 等宽数值,像仪表读数条 |
| 徽章/标签 | 带切角的方框,不是纯圆胶囊 |
| 装饰 | 齿轮、真空管、公式水印散布在边缘 |

## 1. 要新增的结构

### 1.1 切角框(核心,面板/卡片/表格容器/弹窗共用)

替换掉「圆角 + 发丝线」的卡片形状:

```
外框:1px 发丝线,四角用 clip-path 切掉(polygon,切角 10~14px)
角标:四个 L 形角标,2px 粗,长 14px,强调色 55% 透明度,用 ::before/::after +
      background-image 的线性渐变实现(一个伪元素画两个角,两个伪元素画四个)
内边:极淡的第二层线(foreground 6%),内缩 3px,同样切角
```

`clip-path` 与 `border` 不能共存(切角会把边框切掉),所以边框要用
`background: linear-gradient()` 画在切角形状上,或者用一层绝对定位的
`::before` 承载框线。**两种做法都要试,选实测下不出现锯齿的那个**,
并在注释里写明为什么选它。

### 1.2 电路走线(装饰,克制使用)

- **区段头下方**一条走线:水平细线 + 若干节点圆点 + 一处分叉,用内联 SVG data-uri
  做成 `background-image`,`background-repeat: repeat-x`
- **表头下边框**换成走线(同上,但更细更淡)
- **面板右上角**一小段装饰走线(可选)

走线颜色必须从 `--qy-sg-hair-strong` / `--primary` 派生 —— SVG 里读不到 CSS 变量,
所以用 `mask` + `background-color` 的手法(decor 文件里齿轮已经这么做了,照抄)。

### 1.3 侧栏板按钮 + 双语标签

```
[data-slot='sidebar-menu-button'] {
  切角板:clip-path 切左上/右下两角(不是四角,四角切会显得像徽章)
  底:极淡渐变(foreground 3% → transparent)
  边:1px hair
  hover:边框转 primary 40%,底色 primary 5%
  active:边框 primary,内发光 inset 0 0 12px primary/15,外辉光 0 0 16px primary/20
        左侧仍保留 2px 竖线(第一版已有,不要删)
}
```

**双语标签**:侧栏项现在只有中文。英文小号大写标签需要 i18n 新键
(`qy_sg_nav_en_*`),放 `web/src/i18n/qy/{en,zh}.json`,**两个语言文件里都填英文**
(它是装饰性的排版元素,不是翻译)。渲染时 `aria-hidden="true"`,
只在 steins-gate 下出现(复用已有的 `use-qy-theme-preset.ts`)。

### 1.4 表格

第一版做了等宽大写表头,不够。补:

- 表头下边框换成**电路走线**
- 每行右端一条 **3px 状态指示色条**(`td:last-child::after` 或行的 `::after`)。
  颜色按行内是否有 `[data-slot='badge']` 的语义色决定 —— 拿不到语义时用
  `--qy-sg-hair-strong`。**如果实现不了按语义取色,就统一用强调色 40%,
  不要伪造语义**。
- 表格容器套 §1.1 的切角框
- 列头之间的竖向分隔:极淡 1px,只在 hover 行上显现

### 1.5 统计读数条

第一版已经把 `QyStatGrid` 改成发丝线分栏。再进一步:每栏左侧加 3px 色条
(强调色,首栏用实心、其余用 40%),标签移到数值**上方**并改成极小号大写宽字距 ——
与图里的读数条一致。

### 1.6 徽章 / 标签

第一版是纯圆胶囊。图里是**带切角的方框**。改为:`clip-path` 切左上/右下两角,
`border-radius: 2px`,保留等宽大写宽字距。
**注意**:这与第一版「999px 胶囊是身份标识」的说法冲突 —— 按钮保留胶囊,
**徽章改切角**,两者分工。这个改动要在注释里写明推翻了第一版的哪一条。

### 1.7 输入控件

切角(左上/右下)+ 发丝线 + focus 时辉光描边。数值输入等宽。

## 3. 硬性约束(与第一版相同,逐条仍是验收项)

1. 全部规则限定在 `[data-theme-preset='steins-gate']` 内,切到其他预设逐像素不受影响。
2. **上游组件源码一行不改**,靠 `data-slot` 锚点。挂之前先确认 slot 真的存在。
3. 不引入外部网络资源;图形用内联 SVG data-uri。
4. 颜色从标准 CSS 变量 `color-mix` 派生,不硬编码十六进制。
5. `prefers-reduced-motion: reduce` 下停掉循环动画,保留静态形态。
6. 新增用户可见文案走 i18n,key 放 `web/src/i18n/qy/{en,zh}.json`,不跑 `i18n:sync`。

## 4. 验收

**「遮住颜色只看轮廓,能不能认出这不是默认主题」** —— 这是本版唯一的验收标准。

具体到可测项:
- 面板/表格容器/弹窗有切角与角标(实测 `clip-path` 非 `none`)
- 侧栏项是切角板且有英文副标(实测 DOM 里存在该文本节点)
- 表头下边框是 `background-image` 走线而非 `border-bottom` 实线
- 表格行有状态指示色条(实测 `::after` 的 width/background)
- 徽章 `clip-path` 非 `none` 且 `border-radius` 不是 999px
- 切到其他预设后以上全部消失
